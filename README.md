# Epic MMO RPG 🎮⚔️

Масштабная онлайн RPG игра, созданная с использованием современных технологий. Проект включает в себя полноценный серверный бэкенд на Node.js с Socket.IO для реального времени и клиентскую часть на Next.js с продвинутым пользовательским интерфейсом.

## 🌟 Особенности

### 🔥 Игровая механика
- **Многопользовательский режим** - играйте с друзьями в реальном времени
- **7 уникальных рас** - Человек, Эльф, Дворф, Орк, Хоббит, Драконорожденный, Тифлинг
- **8 классов персонажей** - Воин, Маг, Разбойник, Жрец, Рейнджер, Паладин, Чернокнижник, Бард
- **Система прокачки** - развивайте характеристики и изучайте новые навыки
- **Боевая система** - сложная механика боя с критическими ударами, блоками и уклонениями
- **Система квестов** - выполняйте задания и получайте награды
- **Экономика** - торгуйте предметами, управляйте ресурсами
- **Гильдии** - объединяйтесь с другими игроками
- **PvP и PvE** - сражайтесь с игроками или монстрами

### 🎨 Технические особенности
- **Реальное время** - WebSocket соединения для мгновенных обновлений
- **2D игровой мир** - красивая графика на основе Konva.js
- **Процедурная генерация** - динамический мир с различными биомами
- **Умная камера** - плавное следование за персонажем с зумом
- **Оптимизация** - кулинг объектов, сетка для быстрого поиска
- **Анимации** - плавные переходы и эффекты
- **Звуковое сопровождение** - звуки действий и фоновая музыка

## 🚀 Установка и запуск

### Предварительные требования
- Node.js 18+ 
- MongoDB
- Redis (опционально, для продакшена)

### 1. Клонирование репозитория
```bash
git clone <repository-url>
cd epic-mmo-rpg
```

### 2. Установка зависимостей
```bash
npm install --legacy-peer-deps
```

### 3. Настройка окружения
Создайте файл `.env.local` в корне проекта:
```env
# Database
MONGODB_URI=mongodb://localhost:27017/epic-mmo-rpg
REDIS_URL=redis://localhost:6379

# JWT
JWT_SECRET=your-super-secret-jwt-key

# Server
PORT=5000
NODE_ENV=development

# Client
NEXT_PUBLIC_SERVER_URL=http://localhost:5000
```

### 4. Запуск MongoDB
```bash
# Ubuntu/Debian
sudo systemctl start mongod

# macOS с Homebrew
brew services start mongodb-community

# Docker
docker run -d -p 27017:27017 --name mongodb mongo:latest
```

### 5. Запуск игры

#### Полный запуск (сервер + клиент)
```bash
npm run dev:full
```

#### Раздельный запуск
```bash
# Терминал 1 - Сервер
npm run server

# Терминал 2 - Клиент  
npm run dev
```

### 6. Открытие игры
Откройте браузер и перейдите по адресу: `http://localhost:3000`

## 🎮 Как играть

### Создание персонажа
1. При первом запуске вы увидите экран загрузки
2. Введите данные для входа или создайте новый аккаунт
3. Выберите расу и класс персонажа
4. Настройте внешность
5. Подтвердите создание персонажа

### Управление
- **Левый клик** - перемещение персонажа
- **Колесо мыши** - увеличение/уменьшение масштаба
- **Клик по NPC/объектам** - взаимодействие
- **1-8** - использование навыков
- **I** - инвентарь
- **Q** - журнал квестов
- **M** - карта мира
- **ESC** - главное меню

### Интерфейс
- **Левая панель** - статистики персонажа (здоровье, мана, опыт)
- **Правая панель** - трекер квестов и мини-карта
- **Нижняя панель** - панель навыков
- **Чат** - общение с другими игроками
