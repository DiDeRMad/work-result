# Super Online Game Prototype

Это минимальный сетевой прототип (Node.js + WebSocket + Canvas).

## Запуск

1. Установите зависимости сервера:

```
cd server
npm install
```

2. Соберите TypeScript и запустите сервер в режиме разработки:

```
npm run dev
```

3. Откройте браузер на `http://localhost:8080` и откройте несколько вкладок, чтобы увидеть мультиплеер.

## Структура

- `server/` — Express + WebSocket сервер.
- `client/` — статические файлы (HTML/CSS/JS) для браузера.
