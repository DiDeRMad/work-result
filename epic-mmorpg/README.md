- **Открытый мир** с более чем 100 уникальными локациями
- **10 классов персонажей** с уникальными способностями
- **PvP и PvE контент** включая арены, поля боя и рейды

- **Кроссплатформенность** - играйте на PC, мобильных устройствах и в браузере

## 🏗️ Архитектура

```
epic-mmorpg/
├── client/              # React клиент с Babylon.js
├── server/              # Node.js сервер с микросервисами
├── game-engine/         # Игровой движок на TypeScript
├── shared/              # Общий код между клиентом и сервером

├── assets/              # Игровые ресурсы
├── docs/                # Документация

```

### Технологии

**Backend:**
- Node.js + TypeScript
- Express + Socket.IO
- PostgreSQL, Redis, MongoDB
- RabbitMQ для микросервисов
- Docker & Kubernetes

**Frontend:**
- React 18 + TypeScript
- Babylon.js для 3D графики
- Material-UI для интерфейса
- Redux Toolkit для состояния
- Socket.IO клиент

**Game Engine:**
- ECS архитектура
- WebGL рендеринг
- Физический движок (Cannon.js)
- Пространственное индексирование
- Многопоточность с Web Workers

### Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/yourusername/epic-mmorpg.git
cd epic-mmorpg
```

2. Установите зависимости:
```bash
npm install
```

3. Настройте переменные окружения:
```bash
cp .env.example .env
# Отредактируйте .env файл
```

4. Запустите Docker контейнеры:
```bash
docker-compose up -d
```

5. Выполните миграции базы данных:
```bash
cd server
npm run migrate
npm run seed
```

6. Запустите разработку:
```bash
# В корневой директории
npm run dev
```

Игра будет доступна по адресу: http://localhost:5173

## 🎮 Игровой процесс

### Создание персонажа
1. Выберите расу (Человек, Эльф, Гном, Орк и др.)
2. Выберите класс (Воин, Маг, Лучник, Разбойник и др.)
3. Настройте внешность
4. Выберите стартовую локацию

### Основные системы
- **Боевая система** - комбо-атаки, уклонения, блоки
- **Прокачка** - 100 уровней с талантами
- **Крафтинг** - создавайте уникальные предметы
- **PvP** - дуэли, арены 2v2/3v3/5v5, поля боя
- **Подземелья** - от 5 до 40 игроков
- **Мировые боссы** - эпические сражения
